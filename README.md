# 로또 추첨기 (Lotto Number Generator)

웹 브라우저에서 바로 동작하는 한국 로또(6/45) 번호 추첨기입니다. 별도 설치 없이
[lotto.html](lotto.html) 파일을 열면 사용할 수 있습니다.

## 기능
- 1 ~ 45 중 중복 없이 6개 번호 추첨 (오름차순 정렬)
- 1 · 3 · 5 · 10 게임 동시 추첨 (A, B, C… 라벨)
- 실제 로또 규칙에 따른 번호 구간별 공 색상
- 반응형 디자인 + 추첨 애니메이션
- 외부 라이브러리 없는 순수 HTML / CSS / JS 단일 파일

## 디자인 시스템
UI는 Figma 템플릿 *"Real Estate Business Website UI Template — Dark Theme"* 의
디자인 시스템에서 추출한 토큰을 적용했습니다.

| 토큰 | 값 |
|------|----|
| 배경 | `#141414` / 카드 `#1A1A1A` → `#1E1E1E` |
| 브랜드 액센트 | `#703BF7` → `#A685FA` (보라 그라데이션) |
| 텍스트 | `#FFFFFF` / 보조 `#999999` / 흐림 `#666666` |
| 보더 | `#262626` / 액센트 톤 `#423C5D` |
| 폰트 | Urbanist (Medium/SemiBold/Bold) + Inter |
| 반경 | 카드 14px / 알약 버튼 100px |

> 원본 `.fig` 파일(340MB)은 GitHub 용량 제한으로 저장소에서 제외했습니다.

## 사용법
```
lotto.html 파일을 더블클릭 → 브라우저에서 열림 → "번호 뽑기" 클릭
```
